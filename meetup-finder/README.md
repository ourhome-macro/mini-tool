# 朋友聚会地点查找器

一个基于高德地图API的静态网页应用，帮助距离较远的朋友们找到最合适的聚会地点。

## 功能特点

- 📍 **多地点输入** - 支持输入多个朋友的地址，自动转换为经纬度
- 🎯 **中心点计算** - 自动计算所有位置的几何中心
- ⭕ **圆形区域绘制** - 以中心点为圆心，支持1-20km半径调整
- 🔍 **POI搜索** - 在圆形区域内搜索餐厅、咖啡馆、商场等
- 📊 **热门度排序** - 按照高德地图权重自动排序推荐地点
- 📱 **响应式设计** - 支持PC端和移动端访问

## 快速开始

### 1. 获取高德地图API Key

1. 访问 [高德开放平台](https://lbs.amap.com/)
2. 注册/登录账号
3. 进入控制台，创建新应用
4. 添加Key，选择"Web端(JS API)"
5. 复制生成的Key

### 2. 配置API Key

打开 `js/map.js` 文件，找到第6行：

```javascript
apiKey: 'YOUR_AMAP_KEY_HERE',
```

将 `YOUR_AMAP_KEY_HERE` 替换为你申请的API Key。

### 3. 运行项目

#### 方式一：直接打开
双击 `index.html` 文件在浏览器中打开

#### 方式二：使用本地服务器（推荐）
```bash
# 使用Python
python -m http.server 8000

# 或使用Node.js
npx http-server

# 然后访问 http://localhost:8000
```

## 使用说明

1. **添加位置**
   - 在左侧输入框中输入朋友的地址
   - 点击"添加"按钮或按回车键
   - 地图上会显示标记点
   - 至少添加2个位置

2. **设置搜索半径**
   - 使用滑块调整搜索半径（1-20km）
   - 地图上会实时显示圆形区域

3. **选择POI类型**
   - 餐饮服务
   - 购物服务
   - 咖啡馆
   - 茶艺馆
   - 风景名胜

4. **搜索聚会地点**
   - 点击"搜索聚会地点"按钮
   - 系统会自动搜索并排序推荐地点
   - 点击列表中的地点可在地图上定位

## 注意事项

1. **API Key安全**
   - 不要将Key提交到公开仓库
   - 建议在高德控制台设置域名白名单

2. **浏览器兼容性**
   - 推荐使用Chrome、Firefox、Edge等现代浏览器
   - 需要支持ES6语法

3. **网络要求**
   - 需要联网访问高德地图API
   - 建议在HTTPS环境下使用

## 常见问题

**Q: 地图无法显示？**
A: 检查API Key是否正确配置，确保网络连接正常

**Q: 地址解析失败？**
A: 尝试输入更详细的地址信息，如"北京市朝阳区三里屯"

**Q: 搜索不到POI？**
A: 尝试增大搜索半径或更换POI类型
