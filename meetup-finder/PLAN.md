# 朋友聚会地点查找器 - 项目计划
# 在meetpoint文件夹下创建项目
## 项目概述
创建一个静态网页应用,帮助距离较远的朋友们找到合适的聚会地点。通过计算多个位置的几何中心,在指定半径范围内搜索热门地点。

## 核心功能

### 1. 多地点输入
- 支持输入多个朋友的地址/位置
- 使用高德地图地理编码API将地址转换为经纬度
- 在地图上标记所有输入的位置
- 支持添加/删除位置

### 2. 中心点计算
- 计算所有位置的几何中心(平均经纬度)
- 在地图上标注中心点
- 提供可视化的中心点标记

### 3. 圆形区域绘制
- 以中心点为圆心绘制圆形区域
- 支持自定义半径(默认5km,可调整1-20km)
- 圆形区域半透明显示

### 4. POI搜索与排序
- 在圆形区域内搜索POI(餐厅、咖啡馆、商场等)
- 使用高德地图POI搜索API
- 按热门程度排序(使用高德的权重字段)
- 显示POI列表和详细信息

### 5. 交互功能
- 点击POI查看详情
- 显示到各朋友位置的距离
- 提供导航链接

## 技术架构

### 前端技术栈
- HTML5 + CSS3 + JavaScript (原生,无框架依赖)
- 高德地图 JavaScript API 2.0

## API使用说明

### 高德地图API Key配置
需要申请高德地图Web端JS API Key:
1. 访问 https://lbs.amap.com/
2. 注册/登录账号
3. 创建应用,选择"Web端(JS API)"
4. 获取Key并配置到项目中

### 主要API接口
1. **地图显示**: AMap.Map
2. **地理编码**: AMap.Geocoder (地址转坐标)
3. **POI搜索**: AMap.PlaceSearch
4. **圆形区域**: AMap.Circle
5. **标记点**: AMap.Marker

## 注意事项

1. **API Key安全**: 
   - 不要将Key提交到公开仓库
   - 可以使用域名白名单限制

2. **性能优化**:
   - 限制搜索结果数量
   - 使用防抖处理输入
   - 合理设置API调用频率

3. **用户体验**:
   - 提供清晰的错误提示
   - 添加加载状态指示
   - 支持移动端触摸操作

4. **跨域问题**:
   - 高德JS API支持JSONP,无需担心跨域
   - 确保在HTTPS环境下使用
